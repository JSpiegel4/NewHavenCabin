# Riverside Cabin - Bristol, VT

A beautiful riverside retreat website showcasing a cozy cabin rental in Bristol, Vermont.

## 🏡 About

This is a single-page website for a riverside cabin Airbnb rental. The site features:
- Responsive design optimized for all devices
- Modern WebP image format with PNG fallbacks
- Performance-optimized with lazy loading
- Lighthouse CI integration for performance monitoring
- Automated WebP image conversion workflow

## 🚀 Features

- **Modern Design**: Clean, elegant interface with Tailwind CSS
- **Optimized Images**: WebP format with automatic conversion from PNG
- **Performance**: Lazy loading, intersection observer API
- **Accessibility**: Semantic HTML, ARIA labels, keyboard navigation
- **SEO**: Structured data with Schema.org markup
- **CI/CD**: GitHub Actions for automated testing and image optimization

## 📦 Technologies

- HTML5
- CSS3 (Tailwind CSS via CDN)
- Vanilla JavaScript
- GitHub Actions
- Lighthouse CI

## 🔧 Workflows

### Lighthouse CI
Runs on every push to main branch to monitor performance, accessibility, best practices, and SEO scores.

### Image Conversion
Automatically converts PNG/JPG images to WebP format for better performance.
